### Make Your First Request

<Tabs>
  <Tab title="Curl">
    ```curl
      curl -X GET -H "ally-api-key: your_api_key" -H "Content-Type: application/json" -H "Accept: application/json" "https://api.ally.ng/services/media?category=politics&feed_limit=3&page=1&per_page=10"
    ```
  </Tab>
  <Tab title="Python">
    ```python
      import requests

      headers = {
        "Content-Type": "application/json",
        "Accept": "application/json",
        "ally-api-key": "your_api_key"
      }
      response = requests.get("https://api.ally.ng/services/feed?category=politics&feed_limit=3&page=1&per_page=10", headers=headers)
      print(response.json())
    ```

  </Tab>
  <Tab title="JavaScript">
    ```javascript
      const headers = {
        "Content-Type": "application/json",
        "Accept": "application/json",
        "ally-api-key": "your_api_key"
      }
      const response = await fetch("https://api.ally.ng/services/feed?category=politics&feed_limit=3&page=1&per_page=10", { headers });
      const data = await response.json();
      console.log(data);
    ```
  </Tab>
</Tabs>

### Explore Available Endpoints

You can access:

- <span className="text-blue-500 rounded-md bg-white/10 p-1">GET</span> <span className="text-pink-500 text-sm">
    /services/feed
  </span> – Get recent news

- <span className="text-blue-500 rounded-md bg-white/10 p-1">GET</span> <span className="text-pink-500 text-sm">
  /services/clusters/\{cid\}
</span> – Get full cluster data

- <span className="text-blue-500 rounded-md bg-white/10 p-1">GET</span> <span className="text-pink-500 text-sm">
  /services/clusters/\{cid\}/summary
</span> – Get cluster summary (generated by AI)

- <span className="text-blue-500 rounded-md bg-white/10 p-1">GET</span> <span className="text-pink-500 text-sm">
  /services/nairaland/\{post_id\}
</span> – Get Nairaland post data

- <span className="text-blue-500 rounded-md bg-white/10 p-1">GET</span> <span className="text-pink-500 text-sm">
  /services/nairaland/\{post_id\}/comments
</span> – Get Nairaland post comments

Full endpoint reference is available [here](/api-reference/introduction).
