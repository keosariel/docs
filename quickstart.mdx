### Make Your First Request

<Tabs>
  <Tab title="Curl">
    ```curl
      curl -X GET -H "ally-api-key: your_api_key" -H "Content-Type: application/json" -H "Accept: application/json" "https://api.ally.ng/services/media?category=politics&feed_limit=3&page=1&per_page=10"
    ```
  </Tab>
  <Tab title="Python">
    ```python
      import requests

      headers = {
        "Content-Type": "application/json",
        "Accept": "application/json",
        "ally-api-key": "your_api_key"
      }
      response = requests.get("https://api.ally.ng/services/media?category=politics&feed_limit=3&page=1&per_page=10", headers=headers)
      print(response.json())
    ```

  </Tab>
  <Tab title="JavaScript">
    ```javascript
      const headers = {
        "Content-Type": "application/json",
        "Accept": "application/json",
        "ally-api-key": "your_api_key"
      }
      const response = await fetch("https://api.ally.ng/services/media?category=politics&feed_limit=3&page=1&per_page=10", { headers });
      const data = await response.json();
      console.log(data);
    ```
  </Tab>
</Tabs>

### Explore Available Endpoints

You can access:

- <span className="text-blue-500 rounded-md bg-white/10 p-1">GET</span> <span className="text-pink-500 text-sm">
    /services/media
  </span> – Get recent news

- <span className="text-blue-500 rounded-md bg-white/10 p-1">GET</span> <span className="text-pink-500 text-sm">
  /services/media/clusters/\{cid\}
</span> – Get full cluster data

- <span className="text-blue-500 rounded-md bg-white/10 p-1">GET</span> <span className="text-pink-500 text-sm">
  /services/media/clusters/\{cid\}/summary
</span> – Get cluster summary (generated by AI)

- <span className="text-blue-500 rounded-md bg-white/10 p-1">GET</span> <span className="text-pink-500 text-sm">
  /services/nairaland/\{post_id\}
</span> – Get Nairaland post data

- <span className="text-blue-500 rounded-md bg-white/10 p-1">GET</span> <span className="text-pink-500 text-sm">
  /services/nairaland/\{post_id\}/comments
</span> – Get Nairaland post comments

Full endpoint reference is available [here](/api-reference/introduction).

### Rate Limits & Error Handling

- Default rate limit: 30 requests/min
- On hitting the limit, you'll receive a 429 Too Many Requests error.
- All error responses include a JSON body with a message and status_code.

### Authentication

All requests require an API key:

```curl
curl -H "ally-api-key: your_api_key" -X GET "https://api.ally.ng/services/media?category=politics&feed_limit=3&page=1&per_page=10"
```
